# 무료스킬 — Supabase 무료 한도 지키기

**목표: 이 프로젝트를 Supabase 무료 플랜 안에서 쓴다.** 한도를 넘으면 **조직의 모든 프로젝트·앱이 함께 멈춘다**(402, 로그인 불능). 이 프로젝트는 데이빗바이블·스마트주보·물품관리ON·말씀광산 등이 **한 프로젝트를 공유**한다.

| 항목 | 무료 한도 | 기준 시점(2026-11-26) |
|---|---|---|
| Storage | 1GB | 약 572MB (443개 파일) |
| Database | 500MB | 174MB |
| Egress | 5GB/월 | 이전 주기 4.4GB (여유 적음) |

## 작업 전에 반드시 (해당될 때마다)

1. **얼마나 쌓이는가를 한 줄로 적는다.** `개당 크기 × 예상 개수`. 적지 못하면 아직 설계가 덜 된 것이다. 사용자에게 보여 주고 진행한다.
2. **큰 파일은 Supabase 에 올리지 않는다.** 영상·음악·긴 녹음은 **유튜브·워드프레스(호스팅어)에 두고 링크만** 건다. 사진은 업로드 전에 줄인다(현재 1400~1600px, 품질 0.8 안팎. 기록 ‹growth.ts·village.ts› 참고).
3. **업로드 코드에는 상한과 이유 표시를 둔다.** 넘으면 **같은 화면에 이유를 적고** 막는다. 소리 없이 막지 않는다(2026-10-19 학습기록 저장 사고의 교훈).
4. **새 버킷을 만들면 주인을 적는다.** 마이그레이션 주석과 `HANDOFF.md` 에 「어느 앱이 쓰는지·왜 있는지」를 남긴다. 주인을 모르는 버킷은 지우기도 못 한다. `file_size_limit` 도 건다.
5. **다른 앱(스마트주보·말씀광산 등)을 연동할 때** 그쪽이 이 프로젝트에 무엇을 얼마나 올리는지 먼저 확인한다. 이 리포 코드로는 그쪽 업로드를 막을 수 없다 — 모르면 **모른다고 말하고** 확인을 요청한다.
6. **이 앱 밖 자원을 지우기 전**에 코드로 참조를 검색하고(`grep`), 지우는 것은 사용자가 대시보드에서 한다. 삭제는 되돌릴 수 없고 Supabase 는 지운 Storage 파일을 복구해 주지 않는다.

## 플랜을 바꿀 때 — 순서가 전부다

> **먼저 줄이고, 그다음에 Free 로 내린다.** 반대로 하면 즉시 전체 제한이다.

내리기 전에 Usage 에서 확인: **Storage < 1GB, Database < 500MB, Egress < 5GB.**
용량은 **시간 평균(GB-Hrs)** 이라 지운 뒤에도 평균이 내려오기까지 **하루 이틀**이 걸린다. 평균이 1GB 아래로 내려온 것을 **보고 난 뒤에** 변경한다. 전환 직후 로그인·앱이 되는지 확인한다.

## 장애가 났을 때 (로그인 불능·`exceed_storage_size_quota`)

- 코드부터 의심하지 않는다. 응답이 `restricted … quota` 면 용량이다.
- **제한 중에도 SQL Editor 는 열리고 Storage 화면은 안 열린다.** 진단은 SQL 로:
  ```sql
  select bucket_id, count(*) files,
    round(sum((metadata->>'size')::bigint)/1024/1024.0,1) mb
  from storage.objects group by 1 order by sum((metadata->>'size')::bigint) desc;
  ```
- 날짜별 기록은 Usage 의 「Storage Size」 그래프가 전부다(시간 단위 없음).
- 급하면 **Pro 로 올려 즉시 풀고**, 줄인 뒤 평균이 내려오면 Free 로 내린다.

## 정기 점검

- 월 1회 Usage 확인. **Storage 800MB(80%)** 에서 정리한다.
- Usage 알림 메일을 켜 둔다.

## 하지 말 것

- 오래됐다고 버킷을 일괄 삭제하지 않는다(`book-files`·`verse-card-backgrounds` 처럼 오래돼도 쓰이는 것이 있었다).
- `storage.objects` 행을 SQL 로 직접 지우지 않는다. 파일이 남고 용량이 안 줄 수 있다. 대시보드나 Storage API 로 지운다.
- 비밀 값(서비스 키 등)을 코드·채팅에 적지 않는다. 환경변수로만 다룬다.
