# 어근영단어ON — 초3~중3 영어 어휘 (1차 출시)

하루 20~30분. **오늘 배울 단어 확인 → 떠올려 답하기 → 틀린 것 다시 익히기 → 문장에 써보기 →
내일과 주말에 다시 꺼내기.** Expo(React Native) 웹·앱.

데이빗바이블(`../`)과 **별도 앱**이다 — 데이빗바이블은 개인 경건훈련 앱이고 영단어는
경건훈련이 아니다(물품관리ON·살림ON 과 같은 판단). 이 폴더 하나로 서며, 상위 앱의
코드를 한 줄도 부르지 않는다. 제 리포로 옮길 때는 폴더째 떼어 가면 된다.

```bash
npm install
npm run web        # http://localhost:8081
npm run typecheck  # tsc --noEmit
npm test           # 엔진 검사 49개 (노드로 바로, 화면 없이)
```

서버·환경 변수가 필요 없다. **학습 기록은 기기 안(AsyncStorage)에만 있다** — 아이의
기록이라 1차는 밖으로 보내지 않는다(기획서 §7). 보호자는 같은 기기의 「성장 보고서」에서 본다.

## 붙잡고 있는 판단들

- **자기평가 단추가 없다.** 「알아요」를 눌러도 설명 대신 문제가 나온다. 상태는 정오·힌트·
  응답 시간·마지막 성공일로만 정한다(§4.1).
- **예약은 그날의 첫 시도만 본다.** 틀린 뒤 같은 세션에서 다시 맞혀도 내일 다시 본다.
  힌트를 봤거나 오래 걸린 정답은 칸을 올리지 않고 간격만 반으로 줄인다.
- 복습 사다리 `다음 날 → 3일 → 주말 → 10일 → 30일 → 60일` 은 **초기 운영값**이다.
  「최고의 간격」이라 주장하지 않는다(§4.2, §10). 파일럿 결과로 `LADDER` 한 줄만 고치면 된다.
- **영어→뜻은 보기를 바로 보여 주지 않는다.** 먼저 떠올리고 「보기 열기」를 눌러야
  보기가 나오고, 시간도 그때부터 잰다.
- 재시험은 **지난번과 다른 방향**으로 묻는다(영→뜻, 뜻→영, 듣기, 예문 빈칸).
- 철자 한두 글자 차이는 「철자」, 빈칸에 원형을 쓰면 「문장 사용」으로 **까닭을 나눠** 적는다.
  뜻을 몰라 틀린 것과 섞으면 보고서가 거짓말을 한다.
- 복습이 많으면 **새 단어가 줄어든다**(0 이 될 수도 있다). 밀린 날은 하루 45개씩만 꺼낸다.
  토·일은 새 단어 없이 이번 주 약점 + 오래된 단어 점검이고, 결과로 다음 주 새 단어 수를
  ±1 조정한다.
- 오늘 세션을 마치면 **더 꺼내지 않는다**. 20분을 채우려는 반복은 하지 않는다(§3).
- **분해는 뜻이 이어질 때만.** `return`·`report` 는 쪼개지 않는다. 모양이 같아도 뜻이 다른
  접사는 다른 가족이다(im-「~이 아닌」 ≠ im-「안으로」). 철자 변화(happy→happi-)와
  다의어(patient, present)는 「주의」로 붙인다. 어원 이야기는 넣지 않았다.
- 파생어를 배울 때는 **바탕 단어를 먼저 떠올리게** 하고(rewrite ← write), 분해를 본 뒤
  뜻을 예상하게 하고 나서야 뜻을 연다.
- 보고서 맨 위는 새로 배운 개수가 아니라 **7일·30일 뒤 독립 회상률**이다. 처음 본 지
  7~29일 / 30일 넘은 카드의 첫 시도 중 힌트 없이 맞힌 비율. 표본 5 미만이면 비율을 쓰지 않는다.
- 순위·경쟁 없음(§5-8).
