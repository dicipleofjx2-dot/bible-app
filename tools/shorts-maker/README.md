# 설교 쇼츠 메이커

대본/녹음 → 단어·절 단위 9:16 자막 영상. 서버·키 없이 브라우저 안에서만 동작(음성이 밖으로 나가지 않음).
앱(Expo)과 무관한 정적 도구다.

실행: `cd tools/shorts-maker && python3 -m http.server 8000` → http://localhost:8000 (PC 크롬 권장)

- 대본 문법: 한 줄 = 한 절 · `*키워드*` · `[요 3:16]` 줄 머리 = 구절 카드 출처
- 싱크: Whisper 자동(첫 실행 때 모델 다운로드, 대본과 글자 단위로 정렬) / 균등 / 탭 / 수동 보정
- 대본 없이 녹음만 → 받아쓴 글로 절 구성. 녹음 없이 글만 → "글만으로(무음)"
- 출력: mp4/webm(실시간 녹화) · SRT
- `core.js` 는 순수 함수(파싱·정렬·SRT)라 node 로 검사 가능
