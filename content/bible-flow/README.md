# 성경맥잡기 1단계 — 신약편

원고 하나(`nt.cjs`)에서 전자책과 PPT 를 함께 굽는다. **고칠 때는 `nt.cjs` 만 고친다** —
결과물을 직접 고치면 다음에 구울 때 사라지고, 전자책과 PPT 가 서로 다른 말을 하게 된다.

| 결과물 | 파일 |
|---|---|
| 전자책 (A5, Word) | `out/성경맥잡기1-신약편.docx` |
| 과별 PPT (16:9, 발표자 메모 = 원고 본문·질문 답) | `out/성경맥잡기1-신약-N과-*.pptx` |

## 다시 굽기

```bash
npm i --no-save docx@9 pptxgenjs@4   # 앱 package.json 에는 넣지 않는다 (앱이 쓰지 않는 도구)
node scripts/bible-flow/build.cjs
```

## 구성 (6과)

1. 다리: 400년의 침묵 — 신구약 중간기
2. 오신 왕 — 사복음서
3. 퍼지는 복음 — 사도행전 (행 1:8)
4. 세우는 편지 — 바울서신 13권을 사도행전 시간표 위에
5. 견디는 교회 — 일반서신 8권
6. 완성 — 요한계시록

## 원고 규칙

- 본문은 **개역한글**. 앱 DB `ko_ko` 에서 가져와 잡문자(` ! `, `&#x27;`, 백틱)를 걷어냈다.
  DB 의 `krv` 는 이름과 달리 **개역개정**(저작권 있음)이라 쓰지 않았다.
- 연대는 모두 「약」. 본문이 아닌 전통·학설에 기대는 것은 (전통)·(견해)로 밝힌다.
- 학설이 갈리는 곳(갈라디아서 연대, 옥중서신 장소, 계시록 연대·해석)은 한쪽을 단정하지 않는다.
- 글꼴은 맑은 고딕(Windows·Office 기본). 다른 글꼴로 바꾸면 PPT 칸 넘침을 다시 봐야 한다.
