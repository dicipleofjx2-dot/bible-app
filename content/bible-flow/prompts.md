## 1. NotebookLM 용

> 소스 세 개를 올린 뒤, 「스튜디오 → 슬라이드 자료 / 인포그래픽 / 보고서」의 **맞춤 설정(프롬프트)** 칸에 넣는다.
> 한 번에 다 만들기보다 **과별로 나눠** 요청하면 빠지는 내용이 적다(끝 줄의 `[대상]` 만 바꿔 여러 번 돌린다).

```
너는 성경 교육 교재 편집자이자 정보 디자이너다.
소스로 올린 「성경맥잡기 1단계 — 신약편」(전자책·PPT·강의 기록)을 새로 만들어라.
목적: 처음 성경을 공부하는 성인이 신약 27권의 큰 흐름을 맥점 8개로 한눈에 잡게 하는 것.

[반드시 지킬 것 — 구도와 흐름]
1. 8과 순서와 각 과의 맥점 문구를 그대로 둔다.
   1과 3×9=27(성경 전체) / 2과 약(約)=약속(성경의 중심) / 3과 5·13·9(신약의 구조와 무대)
   4과 스토리 청크 7(복음서) / 5과 행 1:8(사도행전의 구조) / 6과 예언의 성취(오순절 성령 강림)
   7과 지도로 확인!(바울의 선교여행) / 8과 봉인된 두루마리가 열린다(요한계시록)
2. 각 과 안의 내용 순서, 표의 항목, 확인 질문과 답은 빼거나 순서를 바꾸지 않는다. 새 주장이나 새 단원을 덧붙이지 않는다.
3. 아래 해석은 교재의 입장이므로 바꾸지 않는다.
   - 신약 구조: 역사서 5(4복음서+사도행전) · 바울서신 13(교리 2 · 옥중 4 · 목회 3 · 교회 4) · 비바울서신 9(히브리서·요한계시록 포함)
   - 복음서 스토리 청크 7개: 6번째는 최후의 만찬까지, 7번째는 겟세마네부터
   - 요한복음 절기 순서: 유월절 → 이름 없는 명절(초막절로 보는 견해도 있음) → 유월절(오병이어) → 초막절 → 수전절 → 유월절
   - 갈라디아서: 남갈라디아설, 1차 전도여행을 마치고 안디옥에 돌아온 뒤 기록
   - 요한계시록: 7인 = 재난의 징조, 7나팔 = 재난의 시작(후 3년 반의 시작 신호), 7대접 = 재난의 내용
     흐름은 재림 → 심판 → 천년왕국 → 백보좌 심판 → 새 하늘과 새 땅, 휴거는 마 24:29–31 순서를 따른다
   - 헤롯 통치 시작 BC 37, 성전 파괴 AD 70
4. 성경 본문 인용은 개역한글판 문구를 소스에 있는 그대로 쓴다. 다른 번역(특히 개역개정)으로 바꾸지 않는다.

[고칠 것 — 문장]
5. 어법에 맞게 다듬고, 뜻이 흐린 문장은 분명하게 고친다. 한 문장에는 한 가지 내용만 담는다.
6. 말투는 선생님이 수업에서 말하는 쉬운 존댓말(~입니다/~합니다)로 통일한다.
7. 낯선 용어(중간기, 공관복음, 옥중서신 등)는 처음 나올 때 한 줄로 풀어 준다.
8. 사실·연대·장절이 소스끼리 어긋나면 고치지 말고 「확인 필요」로 표시해 알려 준다.

[고칠 것 — 도식과 이미지]
9. 글이 길게 이어지는 곳은 도식으로 바꾼다: 연대표, 흐름 화살표, 지도, 구조 나무, 비교표, 가계도.
   - 3과: 신약 27권 5·13·9 구조 나무, 로마 왕정·공화정·제정 연대표, 율리오-클라우디우스 왕조 가계도, 눅 3장 통치자 표
   - 4과: 스토리 청크 7 × 4복음서 범위 표, 요한복음 절기 흐름
   - 5과: 행 1:8 세 지역을 분량(장 수)에 비례한 띠 도식, 사울의 길(기간 표시)
   - 7과: 1·2·3차 전도여행 지도(같은 크기로 나란히, 머문 기간을 원 크기로, 서신 기록 장소 표시), 시기별 바울서신
   - 8과: 요한계시록 장별 구조, 다니엘 → 마 24 → 계시록 흐름, 일곱 교회 지도
10. 한 장(슬라이드)에는 한 가지 메시지만. 글자는 적게, 큰 글씨로.
11. 사진은 실제 유적·유물 사진을 쓴다(티투스 개선문, 통곡의 벽, 헤롯 성전 모형, 빌라도 비문, 에베소 대극장, 파피루스 46 등).
    성경 인물의 얼굴을 지어낸 그림은 쓰지 않는다. 이미지를 새로 만들 때는 지도·도식·상징 일러스트로 한정한다.
12. 각 과 끝에 「오늘의 맥점」 한 장과 확인 질문을 둔다. 마지막에 맥점 8개를 한 장으로 요약한다.

[대상] 1과부터 8과까지 전체   ← 과별로 만들 때는 「3과」처럼 바꿔 넣는다
```

```
## 진행 방식
- 한 번에 한 과씩 만든다. 내가 「다음」이라고 하면 다음 과로 간다.
- 각 과마다 아래 네 가지를 낸다:
  A. 교재 본문 (다듬은 글, 표는 마크다운 표)
  B. 슬라이드 구성표 — | 번호 | 제목 | 화면에 들어갈 글(짧게) | 도식/이미지 | 발표자 메모 |
```
