# 2강 실습 대본

1강에서 만든 **주간 일정 페이지**에 기능 두 개를 붙이고, 한 번 되돌린다.
1강 실습을 못 한 사람은 "주간 일정 한 장짜리 웹페이지를 만들어 주세요"
한 줄로 5분이면 따라올 수 있다.

세 가지 모두 **다섯 걸음**을 그대로 돈다 — 정하기 · 계획 · 만들기 · 확인 · 저장.

---

## A. 오늘 날짜 강조하기 (다 같이, 15분)

강사가 먼저 한 바퀴를 시범으로 돈 뒤, 각자 돌게 한다.

| 걸음 | 이렇게 말합니다 |
| --- | --- |
| **1 정하기** | 오늘 날짜에 해당하는 줄 하나만 눈에 띄게 한다 — 그것만. |
| **2 계획** | "오늘 날짜인 줄만 배경색을 넣어 주세요. 먼저 계획을 알려 주세요." |
| **3 만들기** | 계획이 괜찮으면 "그렇게 해 주세요." |
| **4 확인** | 오늘 줄이 표시되나 · 다른 줄은 그대로인가 · 색이 마음에 드나 |
| **5 저장** | "여기까지 커밋해 주세요." |

색이 마음에 안 들면 **그것도 4번에서 말한다** — "색을 조금 더 연하게 해
주세요." 그리고 다시 확인, 다시 저장.

> **강사 팁**: 화면을 띄워 놓고 "지금 몇 번 걸음이죠?" 하고 물으면 순서가
> 몸에 붙는다.

---

## B. 인쇄 버튼 (각자, 10분)

1. "페이지 위쪽에 인쇄 버튼을 하나 넣어 주세요. 먼저 계획을 알려 주세요."
2. 눌러서 인쇄 창이 뜨는지 확인
3. 다른 것이 안 깨졌는지 확인
4. 커밋

강사는 돌아다니며 막힌 사람을 돕는다. 대부분의 질문은 아래 "자주 나오는
것들" 표 안에 있다.

---

## C. 일부러 되돌리기 (다 같이, 10분) — **오늘의 핵심**

1. "글꼴을 아주 크게 바꿔 주세요" — 일부러 어색하게 만든다
2. 화면을 보고 "이건 아니다" 확인
3. **"방금 한 것을 되돌려 주세요."**
4. 원래대로 돌아왔는지 눈으로 확인

> 되돌아온 것을 **직접 본 사람**만 그다음부터 과감해진다. C를 건너뛰지 않는다.
> 전체가 한 번에 "되돌아왔다"를 경험하는 순간이 이 수업의 정점이다.

---

## 실습 중 자주 나오는 것들

실습 내내 이 표를 띄워 두면 손 드는 질문이 크게 줄어든다.

| 이런 일이 생기면 | 이렇게 합니다 |
| --- | --- |
| 고쳤다는데 화면이 그대로다 | 새로고침을 한 번. 그래도 그대로면 "정말 반영됐는지 확인해 주세요." |
| 부탁한 것 말고 다른 것도 바뀌었다 | "○○만 남기고 나머지는 되돌려 주세요." |
| 빨간 글씨가 떴다 | 통째로 복사해 붙여넣고 "원인부터 찾아 주세요." |
| 무슨 말인지 하나도 모르겠다 | "지금 하신 말을 개발 모르는 사람에게 하듯 설명해 주세요." |
| 세 번 말했는데 계속 안 된다 | 되돌리고, 부탁 문장을 아예 다시 쓴다. |

---

## 숙제

이번 주에 **다섯 걸음을 한 바퀴** 돌아 본다. 무엇이든 좋다.
"완성"이 아니라 **"한 바퀴"**가 숙제다. 작게라도 끝까지 돌아 본 경험이
다음 시간의 재료가 된다.
