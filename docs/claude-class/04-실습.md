# 실습 대본

두 가지 실습을 한다. 합쳐서 25분이면 충분하다.

---

## 실습 1 — 내 손으로 첫 페이지 만들기 (10분)

### 목표
배운 용어(웹페이지 · 계획 · 커밋)를 **써 보는 것**. 결과물의 완성도는
목표가 아니다.

### 단계

**1) 부탁하기**
```
우리 교회 주간 일정을 보여 주는 한 장짜리 웹페이지를 만들어 주세요.
```

**2) 계획 받기**
```
만들기 전에 어떻게 만들지 먼저 알려 주세요.
```
읽어 보고 마음에 들면 "그렇게 해 주세요"라고 한다.

**3) 한 번에 하나씩 고치기**
```
제목 글씨를 지금보다 크게 해 주세요.
```
```
색을 따뜻한 쪽으로 바꿔 주세요.
```
> **강사 주의**: 여기서 "한 번에 하나씩"을 반드시 강조한다. 초보자는 열
> 가지를 한꺼번에 요청했다가 무엇이 바뀌었는지 확인하지 못한다.

**4) 저장하기**
```
여기까지 커밋해 주세요.
```

### 마무리 멘트
"방금 세 가지 용어를 실제로 쓰셨습니다 — 웹페이지, 계획, 커밋.
오늘 처음 들은 말로 이미 일을 시키셨습니다."

## 실습 2 — 에러와 마주 앉기 (10분)

### 목표
에러에 대한 두려움을 없애는 것. **일부러 망가뜨려 본다.**

### 단계

**1)** 실습 1에서 만든 페이지에서 글자 하나를 일부러 지우거나 바꾼다.
(강사가 먼저 시범을 보이면 가장 좋다.)

**2)** 실행해서 빨간 글씨를 만난다.

**3)** 그 글씨를 **통째로** 복사한다. 요약하지 않는다.

**4)** 붙여넣고 말한다.
```
이 에러가 떴습니다. 원인부터 찾아 주세요.
```

**5)** 고쳐지면 한 번 더 묻는다.
```
왜 그랬는지 한 줄로 설명해 주세요.
```

### 여기서 배우는 것
- 에러는 혼내는 말이 아니라 **안내문**이다
- 요약하면 단서가 사라진다
- "왜"를 물어야 다음에 내가 안다
- 되돌릴 수 있으니 겁낼 것이 없다

## 남는 시간이 있을 때 (보너스)

수강생이 **자기 상황**으로 네 칸을 채워 말해 보게 한다.

> 어디서: ______________
> 무엇을: ______________
> 바라는 것: ______________
> 지금은: ______________

한 명이 소리 내어 읽고, 그대로 클로드에게 넣어 본다. 2분이면 되고,
이 수업에서 가장 오래 기억에 남는 순간이 된다.
