# 3강 실습 대본

## 실습 1 — 내 스킬 하나 만들기 (20분)

**오늘 빈손으로 돌아가지 않는 것**이 목표다. 각자 스킬 하나씩 만들어 간다.

| 걸음 | 이렇게 합니다 |
| --- | --- |
| **1 고르기** | 이번 달에 세 번 넘게 한 일을 하나 적는다. |
| **2 설명하기** | "제가 ○○을 할 때 이런 순서로 합니다: …" 말하듯 적는다. |
| **3 만들기** | "이걸 스킬로 만들어 주세요. 이름은 ○○로 해 주세요." |
| **4 써 보기** | 바로 한 번 불러서 결과를 본다. |
| **5 고치기** | 빠진 것이 보이면 "이것도 넣어 주세요." 그리고 다시 한 번. |

무엇을 만들지 모르겠다면:

> **"제가 자주 하는 일 중에 스킬로 만들 만한 걸 같이 찾아 주세요."**

> **강사 팁**: 4번과 5번을 꼭 하게 한다. 만들기만 하고 안 써 보면 그 스킬은
> 다음 주에 잊힌다. **한 번 써서 결과를 본 사람만** 계속 쓴다.

## 실습 2 — 접어 보고, 점검해 보기 (10분)

### 접어 보기

1. `/help` 를 쳐서 접는 명령의 **이름을 찾는다** (외우지 말고 찾는다)
2. 방금 만든 스킬 이야기를 **남기라고 덧붙여** 접는다
3. 접힌 뒤 **"우리가 방금 뭘 했죠?"** 하고 물어본다
4. 남았는지 확인한다

> 남기라고 한 것이 실제로 남았는지 **눈으로 확인**하면 컴팩트가 무섭지 않은
> 것이 된다. 이 확인 동작이 이 실습의 전부다.

### 내 습관 점검 네 줄

- 지금 이 대화, 몇 시간째인가?
- 상관없는 이야기가 섞여 있나?
- 매번 반복해 말하는 문장이 있나? → **규칙이나 스킬로** 옮길 때
- 긴 결과를 화면에 쏟고 있나? → **파일로** 받을 때

## 숙제

오늘 만든 스킬을 **이번 주에 한 번 실제로** 써 본다. 고친 곳이 있으면 그
이야기를 가져온다.

다음 시간 주제는 수강생이 실제로 막힌 곳에서 정한다고 말해 두면 참여도가
올라간다.
