# PPT 다시 만들기

`../클로드-수업-1강-개발용어-첫걸음.pptx` 를 만든 스크립트다. 내용을 고치려면
PowerPoint에서 직접 고쳐도 되고, 여러 장을 한꺼번에 손보려면 여기서 고친 뒤
다시 굽는 편이 빠르다.

```bash
npm install pptxgenjs
node build.js          # → 클로드-수업-1강-개발용어-첫걸음.pptx
```

- `gen.js` — 슬라이드 틀(표지·간지·카드·표·2단·번호목록)과 색·글꼴
- `build.js` — 25장의 실제 내용

글꼴은 **맑은 고딕**으로 지정돼 있다. 맥에서 열면 다른 글꼴로 대체되므로,
맥에서 발표한다면 `gen.js` 의 `F` 값을 `"Apple SD Gothic Neo"` 로 바꿔서
다시 굽는다.

발표자 노트는 `addNotes()` 로 25장 전부에 들어 있다.
