# 클로드에게 말하는 법

용어를 알았으면 이제 문장을 만든다. 어려운 기술은 없다. **병원에서 증상을
말하듯** 하면 된다.

---

## 좋은 부탁에 들어가는 네 가지

| | 무엇을 적나 | 예 |
| --- | --- | --- |
| **어디서** | 화면 이름 또는 파일 이름 | "마이페이지 화면에서" |
| **무엇을** | 대상과 동작 | "로그인 버튼을 눌렀을 때" |
| **바라는 것** | 기대하는 결과 | "홈 화면으로 넘어가야 합니다" |
| **지금은** | 현재 상태 / 에러 전문 | "아무 반응이 없고 이 에러가 뜹니다: ..." |

네 칸을 이어 붙이면 그대로 문장이 된다.

> 마이페이지 화면에서 로그인 버튼을 눌렀을 때 홈 화면으로 넘어가야 하는데,
> 아무 반응이 없습니다. 에러는 이렇게 떴습니다: (붙여넣기)

---

## 바꿔 말하기 연습

| 이렇게 말하면 | 이렇게 바꿔 보세요 |
| --- | --- |
| "이거 좀 예쁘게 해 주세요" | "홈 화면 버튼 글씨가 작아 보입니다. 지금보다 한 단계 크게, 색은 그대로 두고 바꿔 주세요." |
| "안 돼요" | "읽기 화면에서 다음 장 버튼을 눌러도 화면이 그대로입니다. 에러는 없고 반응만 없습니다." |
| "기능 하나 넣어 주세요" | "기도 목록에 검색칸을 넣고 싶습니다. 이름으로 찾을 수 있으면 됩니다. 먼저 계획부터 알려 주세요." |
| "아까 게 나았어요" | "방금 바꾼 것을 되돌려 주세요. 그 전 상태가 맞았습니다." |
| "느려요" | "성경 읽기 화면을 열 때 5초쯤 하얀 화면이 뜹니다. 다른 화면은 괜찮습니다." |

길게 쓸 필요는 없다. **한 문장에 장소·대상·기대**만 들어가면 충분하다.

---

## 복사해서 쓰는 문장들

### 이해할 때
- "이 코드가 무슨 일을 하는지 쉬운 말로 설명해 주세요."
- "이 파일이 왜 필요한지 한 문단으로 알려 주세요."
- "방금 쓴 용어 중에 제가 모를 만한 것을 풀어서 설명해 주세요."

### 시작할 때
- "고치기 전에 계획부터 알려 주세요. 제가 확인하고 진행하겠습니다."
- "두세 가지 방법이 있다면 각각의 장단점을 알려 주세요."
- "이건 제가 처음입니다. 한 단계씩 알려 주시면 따라 하겠습니다."

### 고칠 때
- "에러 전문을 붙여넣겠습니다. 원인부터 찾아 주세요."
- "다른 곳은 건드리지 말고 이 부분만 바꿔 주세요."
- "왜 그렇게 고쳤는지 한 줄로 설명해 주세요."
- "확인까지 해 보고 결과를 보여 주세요."

### 멈출 때
- "방금 한 것을 되돌려 주세요."
- "커밋은 제가 말할 때까지 하지 말아 주세요."
- "이건 하지 말고 ○○만 해 주세요."
- "지우기 전에, 되돌릴 수 있는지 먼저 알려 주세요."

---

## 클로드가 하는 일 / 사람이 하는 일

| 클로드가 잘하는 일 | 아직 사람이 해야 하는 일 |
| --- | --- |
| 코드를 읽고 쉬운 말로 설명하기 | 로그인해서 눈으로 확인하기 |
| 새 화면·기능 만들기, 고치기 | 진짜 폰에서 직접 눌러 보기 |
| 에러 원인을 찾아 고치기 | 비밀번호·인증번호 입력하기 |
| 문서·안내문·자료 작성하기 | 돈이 드는 결정 내리기 |
| 명령을 직접 실행하고 확인하기 | "이게 맞다"는 최종 판단 |
| 저장(커밋)과 배포까지 맡기 | 사용자에게 알리고 설명하기 |

**마지막 눈은 언제나 사람이다.** "다 됐습니다"라는 말을 들어도 한 번은
직접 본다.

---

## 꼭 지킬 다섯 가지

1. 비밀번호·주민번호·카드번호는 **어떤 경우에도 붙여넣지 않는다.**
2. 큰 작업 전에는 **"계획부터 알려 주세요"** 하고 한 번 멈춘다.
3. 저장(커밋)과 내보내기(배포)는 **내가 말할 때만** 하게 한다.
4. "다 됐습니다"라는 말을 들어도 **내 눈으로 한 번 확인**한다.
5. 지우거나 바꾸기 전에 **"되돌릴 수 있나요?"**를 먼저 묻는다.

---

## 잘 안 될 때의 순서

1. **한 번에 하나씩 부탁했는가?** 열 가지를 한꺼번에 말하면 결과를 확인할
   수 없다.
2. **에러를 요약하지 않았는가?** 통째로 붙여넣는다.
3. **어디인지 말했는가?** 화면 이름 하나만 붙여도 달라진다.
4. **바라는 결과를 말했는가?** "안 된다"만으로는 무엇이 되어야 하는지 모른다.
5. 그래도 안 되면 — **"지금까지 무엇을 시도했고 왜 안 됐는지 정리해
   주세요"** 하고 상황을 다시 세운다.
