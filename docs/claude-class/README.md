수강생을 전제로 한다.

## 수업을 여는 방식

1. 개발 경험이 있는 분 손 들어 보게 한다. 대개 아무도 없다. 그게 정상이라고
   말해 준다.
2. "오늘은 코딩을 배우는 시간이 아닙니다. **부탁하는 법**을 배우는
   시간입니다." — 이 한 문장으로 수업의 성격을 못 박는다.
3. 외울 필요 없다고 먼저 말한다. 목표는 **알아듣기**까지다.

## 강사가 조심할 것

- **비유를 먼저, 용어를 나중에.** "프론트엔드는 화면입니다"보다 "식당으로
  치면 손님이 앉는 홀입니다. 그걸 프론트엔드라고 부릅니다"가 남는다.
- **한 장에 한 묶음을 넘기지 않는다.** 용어 다섯 개가 한 장에 있으면 넘길
  때 아무도 따라오지 못한다.
- **영어 발음을 교정하지 않는다.** "커밋"이든 "코밋"이든 뜻이 통하면 된다.
  발음을 고쳐 주면 그 뒤로 입을 닫는다.
- **실습 중 에러가 나면 반긴다.** "잘됐습니다, 이게 오늘 배울 겁니다."
  강사가 당황하면 수강생은 다음부터 시도하지 않는다.
- **모르는 질문이 나오면 그 자리에서 클로드에게 물어본다.** 이것 자체가
  가장 좋은 시연이다.

## 숙제

다음 시간까지 클로드에게 **무엇이든 한 가지** 부탁해 보고, 그때 쓴 문장을
가져오게 한다. 잘된 것보다 **안 된 것**을 가져오라고 하면 2강이 훨씬
풍성해진다.
