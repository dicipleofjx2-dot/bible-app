## 1. 올릴 파일 (AAB)

플레이스토어는 APK 가 아니라 **AAB** 를 받습니다.

```bash
npx eas-cli build --platform android --profile production
```

끝나면 `.aab` 파일을 받아 **프로덕션 → 새 버전 만들기**에 올립니다.

서명은 EAS 가 가진 열쇠(Build Credentials BK7kKvCV9X)로 합니다. 플레이 앱 서명을
켜면 구글이 그 위에 다시 서명하니 그대로 두시면 됩니다. **이 열쇠를 잃어버리면
같은 앱으로 새 버전을 못 올립니다** — EAS 계정(dicipleofjx2)을 지키시면 됩니다.

## 6. 대상 연령 — 한 가지 정하셔야 합니다

이메일 로그인을 연 까닭이 「만 15세 미만 아이들」이었지요. 플레이스토어는 여기서
갈립니다.

- **13세 이상**으로 두면 — 지금 그대로 내시면 됩니다. 13·14세 아이들은 문제없이
  씁니다. **이 쪽을 권합니다.**
- **13세 미만을 포함**하면 — 구글의 「가족 정책」이 걸립니다. 광고·외부 링크·
  사용자 간 소통에 더 센 규칙이 붙고 심사가 길어집니다. 우리 앱은 교회 게시판과
  바깥 사이트 링크(데이빗에듀·주보)가 있어 손볼 곳이 생깁니다.

## 7. 올린 뒤 — 자동 제출

구글 서비스 계정 열쇠(JSON)를 받아 두면 다음부터는 명령 한 줄로 올라갑니다.

```bash
npx eas-cli submit --platform android --latest
```

열쇠 만드는 법: 플레이 콘솔 → 설정 → API 액세스 → 서비스 계정 만들기 → JSON 키
내려받기 → `eas.json` 의 `submit.production.android.serviceAccountKeyPath` 에 경로를
적습니다. **그 JSON 파일은 깃에 올리지 마세요.**
