## 정한 것과 이유

**공개 범위를 칸이 아니라 표로 갈랐다.** 기획서 §5 는 글마다 여섯 단계를 고르게 하지만,
RLS 는 칸을 못 지킨다. 한 표에 민감한 것과 공개할 것을 같이 담고 `visibility` 칸으로
가르면 그 칸을 잘못 쓴 순간 병·가정사가 통째로 열린다. 그래서

- 목장 안에서 서로 보는 것 → `cell_shares` · `cell_gatherings` · `cell_ministries` …
- 담당자만 보는 것 → `cell_nurtures.note` · `cell_care_notes`
- 마을로 나가는 것 → `village_*` (승인을 거쳐 **복사**되어 올라간다)

목장 글이 마을로 가는 길은 한 방향이다: **제안 → 마을장 승인 → 광장**.
마을 화면이 목장 표를 직접 읽지 않는다.

**양육은 숫자만 목장에 보인다.** 화면이 `cell_nurtures` 를 세지 않고
`cell_nurture_summary()` 가 돌려주는 집계만 쓴다 — 셀 수 있으면 읽을 수 있고,
읽을 수 있으면 언젠가 이름이 샌다. 이름이 나가는 것은 본인이 적은 `celebrate`(축하
소식) 한 칸뿐이다. 점수·순위·경고 배지는 두지 않았다(기획서 §2).

**돌봄실은 목자·교역자만 연다.** 「그 목장 사람이면」이 아니다. 돌봄 대상은
`members`(교적)로 가리킨다 — 앱을 안 쓰는 성도도 돌봄의 대상이라, 계정으로 가리키면
빠지는 사람이 생긴다.

**선교실에 계좌 칸이 없다.** 칸이 있으면 개인 계좌가 들어간다. 후원은 안내 문구로만
잇고 교회가 승인한 길로 보낸다(기획서 §2).

**모임 순서는 jsonb 한 칸이다.** 순서는 교회마다 다르고 모임마다 늘었다 줄었다 한다.
표를 따로 만들면 한 모임 만드는 데 여러 번 써야 하고, 화면은 어차피 통째로 읽어
통째로 쓴다. 검색할 일도 없다.

**참석은 답(`reply`)과 출석(`attended`)을 따로 담는다.** 「온다고 했는데 못 온 것」과
「안 온 것」은 목자에게 다른 일이다.

**기도 응답 시각은 트리거가 채운다.** 0076 에서 배운 그대로 — 화면이 채우면 기기
시계가 틀어진 만큼 기록이 틀어진다.

## 선교 카드의 사진·영상 (0086)

- 통은 `village-media`(공개 읽기), 표는 `cell_mission_media`. **경로만 담고 전체 주소는
  담지 않는다** — 통을 옮기면 담아 둔 주소가 전부 죽는다.
- 카드를 **만든 뒤에** 붙인다. 만들기 화면에서 먼저 고르게 하면 갈 곳이 안 정해진
  파일을 들고 있어야 하고, 도중에 그만두면 통에 남는다.
- 사진은 가로 1600px·JPEG 0.8 로 줄여 올린다. 영상은 손대지 않고 **25MB(30초쯤)까지**만
  받는다 — 무료 한도는 저장 용량보다 **전송량**이 먼저 찬다.
- 영상은 expo-video 를 새로 넣지 않고 **WebView(폰) / `<video>`(웹)** 로 튼다. 네이티브
  모듈을 더하면 이미 깔린 APK 에서는 다시 빌드해 받기 전까지 안 보인다.

## AI로 그림·영상 만들기

`src/lib/missionPrompt.ts` 한 곳에서 보낼 글을 만든다. 챗지피티는 `?q=` 로 미리 적어
보내고, 소라는 그 길이 없어 클립보드에 복사해 두고 주소만 연다.

**지켜야 할 것을 화면 안내가 아니라 보내는 글 안에 넣었다** — 안내로만 적으면 그 말은
AI 에게 닿지 않는다. 얼굴을 지어내지 말 것(없는 사람이 그 사역을 한 것처럼 보인다),
그림에 한글을 넣지 말 것(거의 반드시 깨진다)이 프롬프트 끝에 늘 붙는다.

화면만 지웠고 **표는 하나도 안 건드렸다.** 거기 있던 것은 다 옮겼다:

| 있던 것 | 간 곳 |
|---|---|
| 목장 공지 `cell_notices` | 목장 현관 |
| 소통창 `cell_messages` | 소그룹실 아래쪽 |

| 경건생활 상황표 | 그대로 `r2m/leaders` 에 있다 |

모임 보고를 읽기 전용으로 둔 까닭: 새로 적는 자리는 예배당의 모임 기록이다. 두 곳에
적히면 어긋난다. 그래도 옛 글을 못 보게 하면 목장이 지나온 자취가 통째로 사라진다.

`nav.cellRoom` 문구는 남겨 두었다 — 지금은 아무 데서도 안 쓰지만, 지우면 다른 언어
파일과 어긋날 여지만 생기고 얻는 것이 없다.
